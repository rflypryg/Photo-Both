# Photo-Booth Web App 📸

Aplikasi web Photo Booth interaktif yang dibangun menggunakan **React** dan **Vite**. Fitur ini memungkinkan pengguna untuk mengambil foto secara langsung, menggunakan filter menarik, dan menyimpan *photo strip* digital dengan cepat.

## 🚀 Teknologi Utama
- **React** (UI Framework)
- **Vite** (Build Tool & HMR Super Cepat)
- **Tailwind CSS / CSS** (Styling)

## 🛠️ Cara Menjalankan Proyek di Lokal

1. **Clone repository ini:**
   ```bash
   git clone [https://github.com/rflypryg/Photo-Both.git](https://github.com/rflypryg/Photo-Both.git)
   cd Photo-Both
Install dependensi:

Bash
npm install
Jalankan server pengembangan:

Bash
npm run dev
Buka tautan http://localhost:5173 yang muncul di terminal pada browser Anda.
